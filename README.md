# ML Models from Scratch

Implementations of classic machine learning algorithms built from scratch
using only NumPy, to understand how they work under the hood.

## Models
- [x] Linear Regression
- [x] Logistic Regression
- [x] K-nearest Neighbours
- [x] Naive Bayes
- [ ] Decision Tree
- [ ] Perceptron
- [ ] Softmax Regression

## Usage
pip install -r requirements.txt
python linear_regression.py

## Code
Regression models are automatically verbose to show how the gradient descent works(to stop it delete all print statements in the class)
Most models have commented lines of code that are there to give basic understanding of the main class
